# База данных

Простая база данных на Python с хранением метаданных таблиц и записей в JSON-файлах.

## Возможности

- Создание, просмотр и удаление таблиц.
- Добавление, чтение, обновление и удаление записей (CRUD).
- Автоматическая генерация ID для новых записей.
- Проверка типов данных и корректности команд.
- Сохранение данных между запусками программы.
- Вывод записей в виде таблицы с помощью PrettyTable.

## Установка и запуск

Для установки зависимостей используется `uv`.

```bash
uv sync
uv run database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `info <имя_таблицы>` — показать информацию о таблице.
- `help` — показать справку.
- `exit` — завершить работу.

При создании таблицы столбец `ID:int` добавляется автоматически.

Пример:

```text
create_table users name:str age:int is_active:bool
```

## Работа с записями (CRUD)

### Добавление записи

```text
insert into users values ("Sergei", 28, true)
```

ID генерируется автоматически.

### Чтение записей

Вывести все записи:

```text
select from users
```

Вывести записи по условию:

```text
select from users where age = 28
```

### Обновление записи

```text
update users set age = 29 where name = "Sergei"
```

Можно изменить несколько столбцов одной командой:

```text
update users set name = "Alexey", age = 21 where ID = 1
```

### Удаление записи

```text
delete from users where ID = 1
```

## Хранение данных

Метаданные таблиц хранятся в файле `db_meta.json`. Записи каждой таблицы сохраняются отдельно в каталоге `data/`, например `data/users.json`.

Данные сохраняются между запусками программы.
