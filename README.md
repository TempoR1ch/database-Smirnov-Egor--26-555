# Примитивная база данных

Простая база данных на Python с хранением метаданных таблиц и записей в JSON-файлах.

## Возможности

- Создание, просмотр и удаление таблиц.
- Добавление, чтение, обновление и удаление записей (CRUD).
- Автоматическая генерация `ID` для новых записей.
- Проверка типов данных `int`, `str`, `bool`.
- Проверка корректности команд и значений.
- Сохранение данных между запусками программы.
- Вывод записей в виде таблицы с помощью PrettyTable.
- Подтверждение опасных операций перед удалением.
- Обработка ошибок базы данных с помощью декоратора.
- Измерение времени выполнения функций.
- Кеширование результатов чтения записей.

## Установка и запуск

Для управления проектом используется `uv`.

```bash
uv sync
uv run database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу (с подтверждением).
- `info <имя_таблицы>` — показать информацию о таблице.
- `help` — вывести справку.
- `exit` — завершить работу.

При создании таблицы столбец `ID:int` добавляется автоматически.

Пример:

```text
create_table users name:str age:int is_active:bool
```

## Работа с записями (CRUD)

### Добавление записи

```text
insert into users values ('Sergei', 28, true)
```

Значения указываются в порядке пользовательских столбцов. `ID` генерируется автоматически.

### Чтение записей

Вывести все записи:

```text
select from users
```

Вывести записи по условию:

```text
select from users where age = 28
```

### Обновление записи

```text
update users set age = 29 where name = 'Sergei'
```

Можно изменить несколько столбцов одной командой:

```text
update users set name = 'Alexey', age = 21 where ID = 1
```

### Удаление записи

```text
delete from users where ID = 1
```

Перед удалением программа запрашивает подтверждение. Ответ `y` подтверждает операцию, любой другой ответ отменяет её.

### Удаление таблицы

```text
drop_table users
```

Перед удалением таблицы программа также запрашивает подтверждение.

## Декораторы и кеширование

В модуле `decorators.py` реализованы:

- `handle_db_errors` — обрабатывает ожидаемые ошибки базы данных и выводит понятное сообщение.
- `confirm_action(action_name)` — запрашивает подтверждение перед опасной операцией.
- `log_time` — измеряет время выполнения функции с помощью `time.monotonic()`.
- `create_cacher()` — создаёт кеш для сохранения результатов вычислений.

Замер времени применяется к операциям `insert` и `select`. Результаты `select` кешируются по ключу, который зависит от данных и условия выборки.

## Хранение данных

Метаданные таблиц хранятся в `db_meta.json`. Записи каждой таблицы хранятся отдельно в каталоге `data/`, например в `data/users.json`.

Данные сохраняются между запусками программы.
